# Календарь учителя

Локальный календарь уроков на чистых HTML, CSS и JavaScript. Данные хранятся только в `localStorage` текущего браузера.

## Запуск

Откройте `index.html` двойным щелчком или через любой локальный статический сервер. Сборка и установка зависимостей не нужны.

Поддерживаются месячный, недельный и дневной виды, экран «Сегодня», карточки учеников и родителей, одиночные и повторяющиеся уроки, домашние задания, результаты, статусы проведения и оплаты, финансовая сводка, поиск и отображение расписания в часовых поясах Екатеринбурга и Москвы.

В редакторе урока можно поставить ученику от 0 до 5 звёзд за успеваемость. Оценка отображается в дневном расписании и на экране «Сегодня».

В верхнем меню можно скачать полную резервную копию в JSON и восстановить её позднее. В разделе «Финансы» доступен экспорт таблицы месяца в CSV.

## Хранение

Состояние сохраняется под ключом `teacherCalendar.v1`. Для полного сброса удалите этот ключ в инструментах разработчика браузера (Application → Local Storage).
